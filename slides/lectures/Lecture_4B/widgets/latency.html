Where the seconds and the cents go

one request = read the prompt (prefill) + write tokens one by one (decode)

Rates are illustrative; real ones depend on the model, the hardware and the load. Prices: Claude API list prices per million tokens, mid-2026.

A person reads about 5 words ≈ 7 tokens per second: streaming at 60 tokens/s already outruns the reader. Thinking tokens are billed as output but you wait for them before the first visible word.
